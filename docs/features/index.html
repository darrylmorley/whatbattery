Built to be checked

Read-only, unprivileged, and open source.

WhatBattery does not install a daemon, kernel extension, or charging controller. It reads Apple's battery and power interfaces, and when a value isn't available, it says so rather than guessing.

  • No root access
  • No automatic battery-data uploads
  • No invented values when hardware reports nothing
  • Source available on GitHub
