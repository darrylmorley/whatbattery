# WhatBattery 1.6.3

Numbers follow your region's format, and a new diagnostic command for iPhone/iPad batteries. macOS 14 and later, Apple Silicon.

## Numbers now follow your regional settings

Every number on screen (the window, the popover, the reports, the CLI's readable output) now uses your region's decimal separator and thousands grouping: 81,8% and 8.694 mAh in a comma-decimal region, 81.8% and 8,694 mAh in a dot one. Reported by a user whose region writes commas and who was right that the apps ignored it.

Two deliberate exceptions. CSV and JSON exports keep the dot whatever your region, because a comma-decimal file breaks the moment a spreadsheet or script parses it. And the dates inside reports stay in one fixed format (UTC), because a report gets handed to other people and a date must not shift with the machine that printed it. The numbers in those reports do follow your region: a comma is readable anywhere, a shifted date is wrong somewhere.

## A diagnostic command for iPhone/iPad batteries (Pro)

`whatbattery --idevice-raw` prints exactly what each connected device reports about its battery, uninterpreted, in Apple's own format. It exists for one reason: when WhatBattery and another tool disagree about a device we can't reproduce, the raw output settles which reading is honest. If support ever asks you to run it, redirect it to a file and mail it back; the header states exactly what the file contains (device name, model, OS version, UDID, battery data, nothing else).

It asks every question, not just the first that answers, so the output shows what a device's newer and older battery locations each said. Introduced for an iPad Pro 10,5" whose battery health reads 13 points apart in WhatBattery and coconutBattery: the answer is in one of these dumps.

## A thin month no longer poses as an average

The Health tab's Monthly view showed a solid "ø Health" figure even when a month had only two daily readings behind it, which presents an anecdote as an average. A month now needs health readings from five different days before it shows a mean; below that, the row says how many readings it has and that they are too few. This applies to the report exports too, so the table, the PDF and the plain-text report can never disagree about the same month. Cycle counts still show at any sample size, because the latest count is a fact rather than an average.

## Smaller things

- The diagnostic command tries a device's other connection (cable vs Wi-Fi) when the first accepts a session but then fails every question, the same fallback the normal reading path gained in 1.6.2.
- Cards in light mode use a fainter fill with a hairline edge, instead of the grey slab. Dark mode is unchanged.

Read-only as always: WhatBattery never changes how your devices charge.
