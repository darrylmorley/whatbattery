# WhatBattery 1.6.2

Older iPhones and iPads can now be read. macOS 14 and later, Apple Silicon.

## Older devices keep their battery data somewhere else

Devices from before the iPhone 8 and iPhone X generation (late 2017) publish their battery under a different name than everything since. WhatBattery only asked at the newer address, so an older device answered honestly that it had nothing there, and the tab reported it as connected but with no battery. This is why an iPad Pro 10.5" sat unreadable next to an iPhone X that read fine.

WhatBattery now checks the older location whenever the newer one comes up empty. Newer devices are unaffected: they answer the first question, same as before.

One honest caveat: this was built without a pre-2017 device on the bench, so it is correct against the documented shape of the older data rather than proven against hardware. If your older device still will not read, say so and include what the tab reports.

## More careful when a device answers slowly

A question that timed out no longer has its follow-up asked over the same connection, where a late answer to the first question could have been mistaken for the answer to the second. And a junk answer over the cable no longer stops the Wi-Fi connection being tried, so a half-seated cable cannot hide a reading that would have worked.

## Returning to the tab no longer queues a second read

Leaving the iPhone and iPad tab and coming straight back could start a new read while the previous one was still finishing, with the two queueing behind each other. The returning tab now picks up the read already in flight instead.

Read-only as always: WhatBattery never changes how your devices charge.
