# WhatBattery 1.2.2

A small polish release for accessory runtimes. macOS 14 and later, Apple Silicon.

## Improved

- AirPods estimates now read as listening time everywhere: the accessory list, the Pro history view, and the low-battery notification all say "About 40m of listening left" instead of a bare time.
- Short estimates show minutes ("40m") instead of rounding everything under an hour to "<1h", and a value that rounds up to the next unit is shown in that unit ("1h", never "60m").
- The Pro accessory history line, the live rows, and the alert all share one formatter now, so the wording can no longer drift between them.

Read-only as always: WhatBattery never changes how your devices charge.
